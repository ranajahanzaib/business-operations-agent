# Contributing

Contributions are welcome. To propose a change:

1. Fork the repository and clone your fork.
2. Create a branch for the change.
3. Make the change and add tests where appropriate.
4. Run the relevant checks described in [docs/development.md](docs/development.md).
5. Commit with a clear, descriptive message and push the branch to your fork.
6. Open a pull request against `main`. Describe the change and include relevant test results.
7. Respond to review feedback and update the pull request as needed.

For bugs and feature requests, use the repository's GitHub issue templates. Do not include real credentials, personal data, or undisclosed vulnerability details in public issues. See [SECURITY.md](SECURITY.md) for vulnerability reports.
